Looking up.

We start on the ground with phones and laptops. Space is where we want to end up, and the way there is tough, efficient hardware.

Made to come apart.

Every part of a Meridian device is designed so it can be opened, understood and repaired.

Every piece has a job.

Space hardware is built so each stage can be checked and replaced on its own. We want phones and laptops that work the same way.

Then it goes back together.

Repair, reuse, rebuild. That is how we plan to cut waste on the ground, and how we want to work in space.

Concept illustration of a generic rocket. Meridian is not building rockets yet; space is a long-term goal. Scroll to take it apart and put it back together.

How we get there.

Learn from tough hardware

Devices that survive years of drops, heat and daily use teach us how to build things that last.

Build for orbit

Efficient, durable electronics are the same discipline spacecraft need. This is where we expect to start working with space.

Launch, one day

Rockets are a long way off and need huge resources. We will only go there once the earlier steps are working.
